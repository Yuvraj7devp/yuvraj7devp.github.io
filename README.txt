BEFORE PUBLISHING:
1. Add your portrait as images/imagefolio.png. If you only have imagefolio.png in the root folder, either move it into images/ or change the image path in index.html.
2. Add your resume as resume/Yuvraj_Bachhav_Data_Analyst_Resume.pdf.
3. Replace illustrative project preview graphics with genuine dashboard/project screenshots if available.
4. Check the IABAC certificate: add a public verification link or place the PDF in the website and link to its relative path. Do not use file:/// links.
5. Verify internship status and responsibilities before publishing.
6. Test all certificate links and resume download.

LOCAL PREVIEW:
Open index.html directly in a browser or use Visual Studio Code with the Live Server extension.

GITHUB PAGES:
Upload the contents of this folder to the repository you use for GitHub Pages. Keep index.html at the published root. Ensure the images/ and resume/ folders are also uploaded. In GitHub, open Settings > Pages and select the correct deployment source/branch.

The demo charts are illustrative sample data and are labeled as such. The project preview cards are CSS-based illustrations, not real dashboard screenshots.
